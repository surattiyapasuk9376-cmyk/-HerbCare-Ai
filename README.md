# 🌿 HerbCare AI 🍵

AI prototype สำหรับให้ข้อมูลเบื้องต้นเกี่ยวกับ
การรับประทานชาสมุนไพรในผู้ป่วยโรคเบาหวาน

## ✨ Features

- คำนวณ BMI จากน้ำหนักและส่วนสูง
- รับข้อมูลอายุ
- รับข้อมูลโรคประจำตัว
- รับข้อมูลยาที่กำลังใช้
- เลือกชนิดชาสมุนไพร
- สร้างคำแนะนำเบื้องต้น
- แจ้งเตือนเรื่องโรคประจำตัวและยาที่อาจเกี่ยวข้อง
- มีระบบอ่านคำแนะนำออกเสียงภาษาไทย
- UI น่ารัก ใช้งานง่าย

## ⚠️ Medical Disclaimer

โปรเจกต์นี้เป็นเพียงต้นแบบเพื่อการศึกษา
ไม่ใช่เครื่องมือวินิจฉัยหรือรักษาโรค

ไม่ควรหยุดยาเบาหวานหรือเปลี่ยนแผนการรักษา
เพราะคำแนะนำจากระบบ

ผู้ที่มีโรคประจำตัวหรือกำลังรับประทานยา
ควรปรึกษาแพทย์หรือเภสัชกรก่อนใช้สมุนไพร
